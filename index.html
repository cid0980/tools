How to run the helper (2 minutes)

1. Install the two real tools: yt-dlp and ffmpeg. On Android use Termux: pkg install python ffmpeg && pip install -U yt-dlp deno. On Windows: winget install yt-dlp.yt-dlp Gyan.FFmpeg DenoLand.Deno. On macOS: brew install yt-dlp ffmpeg deno.

2. Download fetch.mjs with the button above (Node 18+ is enough — no npm install).

3. Paste the command from this page into a terminal, or run node fetch.mjs --json spec.json using the JSON version above.

YouTube specifically: install deno. Since 2026 yt-dlp needs a JavaScript runtime to solve YouTube's signature challenges; without it you get 403 errors and only low-quality formats.

Downloading responsibly
Download what you have the right to download — your own uploads, Creative Commons material, or content whose licence allows it. Respect each platform's terms and your local copyright law.
